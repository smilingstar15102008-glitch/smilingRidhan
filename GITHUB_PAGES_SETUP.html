🐛 Troubleshooting

Site Not Loading?

  • Wait a few minutes for the build to complete
  • Check the "Pages" settings in your repository settings
  • Verify the source branch is set to "main"
  • Clear your browser cache

Getting 404 Errors?

  • Make sure index.html exists in the root directory
  • Check that file paths are relative (not absolute)
  • Verify all HTML files are in the root of the repository

Games or Weather Not Working?

  • Check browser console for JavaScript errors (F12)
  • Verify APIs are accessible (internet connection)
  • Try a different browser
  • Clear browser cache and cookies
